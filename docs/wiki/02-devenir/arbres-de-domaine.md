# Les arbres de domaine

Trente-six domaines structurent tout ce qu'on peut devenir : vingt-quatre voies de
combat, cinq récoltes, sept métiers d'artisanat. Chacun possède son arbre de
compétences, nourri par [la pratique](on-devient-ce-quon-fait.md).

## Les vingt-quatre voies de combat

Chaque arbre de combat est ancré dans un **élément** et un **registre** — sorts,
mêlée ou distance. C'est cette ancre qui décide de ce que ses passifs servent.

| Élément | Voies |
|---|---|
| Feu | Pyromancien, Berserker, Artificier |
| Eau | Hydromancien, Guérisseur, Marémancien |
| Air | Foudromancien, Archer, Vagabond |
| Terre | Géomancien, Défenseur, Gardien |
| Métal | Soldat, Chevalier, Ingénieur |
| Bête | Chasseur, Dompteur, Druide |
| Lumière | Paladin, Prêtre, Inquisiteur |
| Ténèbres | Assassin, Nécromancien, Sorcier |

## Les récoltes et les métiers

- **Cinq récoltes** : Mineur, Herboriste, Pêcheur, Dépeceur, Bûcheron.
- **Sept artisanats** : Forgeron, Tanneur, Alchimiste, Joaillier, Cuisinier,
  Charpentier, Tailleur.

## Ce qu'un arbre contient

Un nœud d'arbre ne donne **jamais un sort actif**. Il donne :

- des **passifs** — dégâts, soin, précision, critique, points de vie ;
- des **accords de matéria** — le prérequis pour utiliser une
  [matéria](materia.md) donnée en combat ;
- des **prérequis d'équipement** — certaines pièces demandent d'avoir appris le
  geste qui permet de les porter.

Lancer un sort passe toujours par une matéria possédée, accordée et sertie ;
l'arbre vous apprend à l'entendre, il ne la remplace pas.

## La double borne des passifs

Un passif pris dans un arbre s'applique **uniquement aux gestes de sa case** : le
critique du Pyromancien ne sert que les sorts de feu — jamais un coup d'épée, jamais
un sort d'eau. Et il ne s'exprime que si votre équipement porte une source de ce
domaine (voir [l'équipement est le build](equipement-et-build.md)). Seuls les
points de vie échappent à cette règle : votre vie n'est pas un geste, elle vous
suit partout.

Monter beaucoup d'arbres n'est donc jamais inutile — mais à chaque instant, seuls
parlent ceux que vous portez.

## Les branches d'artisanat

Chaque métier d'artisanat propose, une fois une solide expérience acquise dans son
arbre, un choix entre **deux branches** — une identité qui se raconte en une
phrase :

| Métier | Branches |
|---|---|
| Forgeron | armes / armures |
| Alchimiste | remèdes / toxines |
| Tanneur | armures / harnachement |
| Joaillier | focus / parure |
| Cuisinier | table de fête / vivres de route |
| Charpentier | armes de trait / mobilier |
| Tailleur | robes de sort / tenues de travail |

La branche choisie ouvre les nœuds terminaux de son côté de l'arbre, améliore vos
chances de qualité sur vos ouvrages, et **ferme l'autre côté**. Le choix se joue
arbre par arbre : être forgeron d'armes ne vous interdit jamais de devenir aussi
tanneur, ni alchimiste. En changer est possible, mais c'est le seul renoncement
payant du jeu : **2 500 gils** pour défaire une identité et en prendre une autre.

## Les accords silencieux

Les curieux remarqueront, dans certains arbres, des nœuds visibles mais clos —
« pas encore ouverts », dit l'écran. Il se murmure que certains arbres gardent un
accord silencieux, en attente de quelque chose que le monde n'a pas encore vu.
